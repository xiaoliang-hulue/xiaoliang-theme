图标形变 Icon Morph

在两个 Lucide 图标之间做路径形变，介于静态图标与 Lottie 动画图标之间 · 图标源仍只有 assets/icons/lucide.min.js（v1.8.0）

尺寸档位

尺寸由 --morph-icon-size 控制，内置 .is-xs(16px) / .is-sm(18px) / 默认(24px) / .is-lg(28px) / .is-xl(40px) 五档；颜色继承当前的 color，因此放进主色按钮会自动跟随按钮前景色。

is-xs → is-xl 鼠标悬停或键盘聚焦即可预览

触发器

data-morph-trigger 四选一：click（默认）、hover、view（进入视口播放一次）、state（与 aria-pressed 双向绑定）。data-morph-speed 可选 fast / base（默认）/ slow / emphasis。

click（默认） 点击在两侧图标间来回形变；Enter / Space 等效。非按钮元素会被自动补上 role="button" 与 tabindex="0"。
hover 悬停进入目标图标，移出返回起始图标；键盘聚焦同样生效。
view 首次进入视口时播放一次，播放后停止观察，适合列表项与卡片。
state 点击翻转 aria-pressed，形变与语义状态同步；外部直接改属性也会跟着动。
<i> + click 这里用 <i> 承载；data-morph-label 会在运行时写成 aria-label，等价于直接写 aria-label。

与既有组件组合

形变图标本身就是 Lucide v1.8.0 的图标，因此可以和 data-lucide 静态图标并存于同一页，也可以直接嵌进按钮、提示条等既有组件。

按钮内 按钮内的形变图标由 .btn .morph-icon 统一为 18px，颜色继承按钮前景色。
提示条内
校验通过：形变图标沿用 .alert 的 18px 尺寸约定，不需要额外样式。
与静态图标并存 左侧是 data-lucide 运行时图标，右侧是形变图标，图标源同为 assets/icons/lucide.min.js。

动效与无障碍

系统 prefers-reduced-motion: reduce 或 <html data-motion="off"> 时，形变直接跳到目标图标，不播放补间（与主题动效契约一致）。

形变只改写 <path d>，不产生布局位移、不改变元素尺寸，因此不会引起重排或滚动锚点跳动。

装饰性用法自动获得 aria-hidden="true"；交互式用法必须提供可访问名（aria-label 或 data-morph-label），缺失时控制台会给出警告。

data-morph-speed 映射到主题节奏：fast / base 约 180ms，slow 约 280ms，emphasis 约 420ms，不使用会过冲的弹性档。

运行时是 vendored 的 morphicons@1.7.1（MIT，min 16 KB），不含任何网络请求，可在 file:// 与严格 CSP（connect-src 'none'）下工作。
